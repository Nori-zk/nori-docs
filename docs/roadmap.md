# Roadmap

Nori-zk is an Ethereum → Mina zero-knowledge bridge.

The project is currently in **pre-audit hardening**: feature-complete, with
work focused on review, testing, and documentation ahead of an external
security audit.

This documentation site is in active development. Pages will be expanded and
new sections added as material is ready for public review.
