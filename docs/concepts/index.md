# Concepts

This section explains the cryptographic and protocol primitives Nori-zk is
built from: Ethereum light clients (and Helios in particular), the SP1 zkVM
and the zero-knowledge proofs it produces, the Mina protocol as a ZK-native
destination chain, and the proof-conversion step that bridges the two proof
systems.
